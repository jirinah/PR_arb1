
**Prosjekt**: Programmering arbeidskrav 1

	Innhold: python program for å hente data fra API med nøkkel (strømpriser) og uten nøkkel (catfacts).

	Hensikt: lære hvordan hente og lagre API-nøkkel trygt vha python keyring; lære å hente data fra API med og uten nøkkel.


**_Før du kjører, så trenger du:_**

	En API-nøkkel fra https://strompriseridag.no/api/ 
	
	API-nøkkelen må være lagre med python keyring for å kjøre strømpriser_API.py. 
	
	Installerte pakker i ditt virtuelle miljø: keyring; requests; json. 


_**Kjøre python programmene:**_

    Instruksjoner for hvordan programmene kjøres er beskrevet som kommentarer i .py filene.


_**Anvendelighet og problemer**_

Programmet ble laget i VScode (python 3.13) på MacBook Air (OS version 15.8.1). Usikker om hvor anvendelig dette programmet er i andre omstendigheter.
